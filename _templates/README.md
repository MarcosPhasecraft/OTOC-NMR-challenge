# Templates

Copy these four files to your repo root when you start a new problem
(`CONTEXT.md`, `PLAN.md`, `NOTES.md`, `CLAUDE.md`), then fill in the
bracketed placeholders. See `PLAYBOOK.md` at the repo root for what each
one is for and when to write it.

```bash
cp _templates/CONTEXT.md _templates/PLAN.md _templates/NOTES.md _templates/CLAUDE.md .
```

Also copy `run.py` once you reach Step 5/6 (a generator exists and you
want to run it via the toolkit's CLI):

```bash
cp _templates/run.py .
```
